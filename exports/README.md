# Exports

Ce dossier contient les résultats du scraping automatique.

## Fichiers

### Tous les jobs
- `jobs_latest.json` - **Tous les jobs** scrapés (format JSON)
- `jobs_latest.csv` - **Tous les jobs** scrapés (format CSV)

### Jobs remote uniquement
- `remote_jobs_latest.json` - **Jobs remote uniquement** (format JSON)
- `remote_jobs_latest.csv` - **Jobs remote uniquement** (format CSV)

### Tutoring (tutorat en ligne)
- `tutoring_opportunities_latest.json` - **Demandes de tutorat en ligne** (format JSON)
- `tutoring_opportunities_latest.csv` - **Demandes de tutorat en ligne** (format CSV)

### Tutoring STEM (priorité)
- `tutoring_stem_opportunities_latest.json` - **Tutorat STEM remote** (format JSON)
- `tutoring_stem_opportunities_latest.csv` - **Tutorat STEM remote** (format CSV)

### Archives (snapshots horodatés)
- `archive/jobs_YYYYMMDD_HHMMSS.json/csv`
- `archive/remote_jobs_YYYYMMDD_HHMMSS.json/csv`
- `archive/tutoring_opportunities_YYYYMMDD_HHMMSS.json/csv`
- `archive/tutoring_stem_opportunities_YYYYMMDD_HHMMSS.json/csv`
